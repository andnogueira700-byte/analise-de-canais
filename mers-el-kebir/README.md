# Mers-el-Kébir (3 luglio 1940) — Lógica di Guerra

Projeto de vídeo (outro canal, 2ª Guerra). Aqui ficam só arquivos leves: roteiro, pesquisa, storyboard e prompts de música.
Os arquivos pesados (áudio, renders, vídeos baixados) ficam fora do repositório.

- `roteiro/` — legendas SRT do narrador (legenda, sincronia por tempo, por palavra)
- `pesquisa/jornais/` — capas de jornais de julho de 1940 (Library of Congress, Chronicling America, domínio público)
- `pesquisa/videos-links/` — links de vídeos de arquivo para o usuário baixar
- `storyboard/` — storyboard para aprovação
- `musica/` — prompts detalhados para o Flow Music

Duração do áudio: 15:22 (922 s).
